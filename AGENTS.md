### UI Copy Rules
- All user-facing text must be written for non-technical content creators.
- Never mention implementation details in UI copy: client-side/server-side, frameworks, libraries, APIs, codecs, model/vendor names, or internal enum/preset keys.
- Describe benefits and outcomes (speed, free, no watermark, easy), not technology.
- When adding or editing any text, check it against these rules first.
- Technical details are allowed only in code, comments, and developer docs, never in the UI.
